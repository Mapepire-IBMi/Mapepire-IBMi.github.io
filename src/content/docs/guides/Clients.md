Mapepire has clients for many languages and runtimes. Each client has its own GitHub project, and some have a usage guide on this site to help you get started.

### Status definitions

| Status | Meaning |
|---|---|
| ✅ **Tier 1** | Actively maintained. |
| **Tier 2** | Validations have shown promising results. Suitable for proof-of-concept (PoC) work. |
| ⚠️ **Experimental** | Exploratory only. Use at your own risk. |
| **Planned** | Not yet available. The project exists, but no usable client has been released. |
